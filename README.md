China by Numbers is a small, offline statistics explorer for China, built from real 2024 National Bureau of Statistics figures: 1,408.3 million people, ¥134.9 trillion of output growing 5.0%, ¥95,749 of output per person, a 79.0-year expected lifespan and 67.0% of people living in towns and cities. It has five pages — Overview, Economy, People, Regions and Living — with an output chart you can redraw from any starting year, age-band and sector bars, and a table of the ten biggest provinces that you can search and sort. It is plain static files, works on a desktop and on a phone, and loads nothing from the network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The hand-in program is `node main.ts` (see `MAKEFUN_OUTPUT_DIR`).
